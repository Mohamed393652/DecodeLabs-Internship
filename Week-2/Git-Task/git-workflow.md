# Git Workflow

The basic Git workflow used in this project is:

1. Create or modify files in the working directory.
2. Check changes using `git status`.
3. Stage changes using `git add`.
4. Save changes using `git commit`.
5. Upload commits to GitHub using `git push`.

## Repository Workflow

```text
Working Directory
       ↓
   git add
       ↓
 Staging Area
       ↓
  git commit
       ↓
 Local Repository
       ↓
   git push
       ↓
     GitHub
